🖥 Remote desktop options
Remote desktops run through guacd (the Apache Guacamole proxy) next to WRM. The browser shows the screen; keyboard, mouse, clipboard and audio are passed through.

⚡ Out-of-band management (iDRAC, iLO, IPMI)
The management controller (BMC) of the server: power on, off and restart, health, and the serial console — also when the operating system does not answer. Redfish works with iDRAC, iLO, XClarity, Supermicro and OpenBMC; IPMI uses ipmitool.
🔀 SSH tunnels (port forwarding)
Local (-L): a port on the WRM machine leads to a host:port as seen from this server (e.g. the web interface of an internal device). SOCKS (-D): a proxy for your browser or tools that reaches everything this server reaches. Remote (-R): a port on this server leads back to a host:port reachable from WRM. Tunnels go through the jump hosts too.

🔑 SSH keys & credentials

    

      
      
      
    

    

      
Your SSH keys, stored encrypted on the WRM server. Generate a key or import one, put it on servers (like ssh-copy-id, through jump hosts too) and let connections log in with it. "Who has access" on an SSH connection shows which keys can log in there.

      

        
        
        
      

      

    

    

      
A credential is a user name with a password (or an SSH key) that many connections log in with, e.g. root@dc1. Change it once and every connection uses the new one. Share it with colleagues: they can use it but never see it. Rotation changes the password on all its SSH servers at once.

      

      

    

    

      
SOCKS5, SOCKS4/4a and HTTP CONNECT proxies, or a SOCKS tunnel (-D) of one of your connections that WRM starts when needed. Choose one in a connection (Proxy) or as a folder default. Share it with colleagues: they can use it but never see its login.

The key is created on the WRM server and stored encrypted; the private key leaves it only if you export it. ED25519 is short and fast; use RSA only for old servers. RSA keys take a few seconds.

    

    

      

        
OpenSSH or PEM private keys (ED25519, RSA, ECDSA). A public key alone (e.g. a colleague's) can be put on servers, but WRM cannot log in with it. PuTTY .ppk: export it with PuTTYgen → Conversions → Export OpenSSH key first.

📣 Broadcast input

    
What you type in one of the selected terminals is sent to all of them at the same time — run the same command on many servers. Commands that look dangerous (rm -rf, shutdown, mkfs, DROP TABLE…) and pasted multi-line text ask for confirmation first. Snippets run on every selected terminal with their own host and user.

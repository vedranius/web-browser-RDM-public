# WRM PRO help

This is the same help that WRM PRO shows in the app (the **?** button in the top bar, or F1). Every feature has an article in English and Croatian; in the app you can also search them and ask the help AI.

Ova ista pomoć prikazuje se u aplikaciji (gumb **?** u gornjoj traci ili F1). Svaka funkcionalnost ima članak na engleskom i hrvatskom.

The articles live in [`remote-manager/help/`](../remote-manager/help/) and are built into the WRM binary. To improve one, edit its Markdown file (both languages) and open a pull request. `go test -run TestHelp` checks both languages and this index; `WRM_WRITE_HELP_INDEX=1 go test -run TestHelpDocsIndex` rewrites the index.
